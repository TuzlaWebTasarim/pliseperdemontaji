# Plise Perde Montajı

Türkiye'nin lider plise perde montaj hizmeti. Özel ölçü üretim, profesyonel kurulum ve Avrupa'ya teslimat.

## Teknoloji Stack

- Next.js 14
- TypeScript
- TailwindCSS
- React 18

## Kurulum

```bash
npm install
npm run dev
```

Proje http://localhost:13166 adresinde çalışacaktır.

## Üretim

```bash
npm run build
npm start
```
